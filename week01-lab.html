3  1주차 코딩 실습

이 실습은 1장에서 만든 학습 루프 템플릿을 손으로 완성하고 확장하는 과정입니다. 예제 코드를 먼저 실행해 동작을 확인한 뒤, 실습문제의 빈칸(# TODO)을 채워 제출합니다.

3.1 예제 코드

아래는 원(circle) 모양 데이터를 분류하는 완성된 예제입니다. make_circles는 안쪽 원과 바깥쪽 원을 두 클래스로 나눈 비선형 데이터입니다.

import torch, torch.nn as nn, torch.optim as optim
from torch.utils.data import TensorDataset, DataLoader, random_split
from sklearn.datasets import make_circles
from sklearn.preprocessing import StandardScaler

device = "cuda" if torch.cuda.is_available() else "cpu"
torch.manual_seed(0)

X, y = make_circles(n_samples=1500, noise=0.15, factor=0.4, random_state=0)
X = StandardScaler().fit_transform(X)
X = torch.tensor(X, dtype=torch.float32)
y = torch.tensor(y, dtype=torch.float32).unsqueeze(1)

ds = TensorDataset(X, y)
n = len(ds); n_tr, n_va = int(0.7*n), int(0.15*n)
tr, va, te = random_split(ds, [n_tr, n_va, n-n_tr-n_va],
                          generator=torch.Generator().manual_seed(0))
tl = DataLoader(tr, batch_size=64, shuffle=True)
vl = DataLoader(va, batch_size=256)
el = DataLoader(te, batch_size=256)

model = nn.Sequential(nn.Linear(2,32), nn.ReLU(),
                      nn.Linear(32,32), nn.ReLU(),
                      nn.Linear(32,1)).to(device)
crit = nn.BCEWithLogitsLoss()
opt  = optim.Adam(model.parameters(), lr=1e-2)

def run(loader, train):
    model.train() if train else model.eval()
    tot_l = tot_c = tot_n = 0
    with torch.set_grad_enabled(train):
        for xb, yb in loader:
            xb, yb = xb.to(device), yb.to(device)
            out = model(xb); loss = crit(out, yb)
            if train:
                opt.zero_grad(); loss.backward(); opt.step()
            tot_l += loss.item()*len(xb)
            tot_c += ((torch.sigmoid(out)>0.5).float()==yb).sum().item()
            tot_n += len(xb)
    return tot_l/tot_n, tot_c/tot_n

for ep in range(1, 31):
    run(tl, True)
print("test acc:", round(run(el, False)[1], 3))

교수용 정답 및 해설

문제 1 정답 및 해설

활성화 함수를 선택해 층 목록에 추가하면 됩니다.

def make_model(act="relu"):
    layers = [nn.Linear(2, 32)]
    if act == "relu":
        layers.append(nn.ReLU())
    elif act == "tanh":
        layers.append(nn.Tanh())
    elif act != "none":
        raise ValueError("act는 relu, tanh, none 중 하나여야 합니다.")
    layers += [nn.Linear(32, 32)]
    if act == "relu":
        layers.append(nn.ReLU())
    elif act == "tanh":
        layers.append(nn.Tanh())
    layers.append(nn.Linear(32, 1))
    return nn.Sequential(*layers)

none은 선형층의 합성이 다시 하나의 선형 변환이 되므로 반달 모양의 비선형 경계를 충분히 표현하지 못합니다. ReLU와 Tanh의 정확도는 난수와 학습 조건에 따라 달라질 수 있으므로 여러 seed의 평균으로 비교하는 것이 좋습니다.

문제 2 정답 및 해설

검증 정확도가 갱신될 때 state_dict의 각 텐서를 복사합니다. 단순히 사전을 대입하면 이후 학습에서 값이 함께 바뀔 수 있습니다.

best_acc, best_state = -1.0, None
for epoch in range(EPOCHS):
    train_loss, train_acc = run_epoch(model, train_loader, criterion, optimizer)
    val_loss, val_acc = run_epoch(model, val_loader, criterion)
    if val_acc > best_acc:
        best_acc = val_acc
        best_state = {k: v.detach().cpu().clone()
                      for k, v in model.state_dict().items()}

model.load_state_dict(best_state)
test_loss, test_acc = run_epoch(model, test_loader, criterion)

Test set은 최적 모델 선택에 사용하지 않고 마지막 성능 확인에만 사용합니다.
